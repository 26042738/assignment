Description
A Java application developed to manage Extreme IT Products. It allows users to capture, search, update, delete, and view product information.
FEATURES
Capture new products
Search products using product codes
Update warranty, price, and stock
Delete products
Generate a product report
Exit the application

PRODUCT CATEGORIES 

Desktop Computer
Laptop
Tablet
Printer
Gaming Console

CLASSES
Products – Contains the main application methods.
ReportData – Contains the getters and setters for report information.
Main – Runs the application.
